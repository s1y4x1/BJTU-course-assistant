【六、点击圣诞树 → 中央手写 "Merry Christmas"】
- 结构：#mc-check（display:none 的 checkbox）、#xmas-tree（label[for=mc-check]）、#mc-overlay（label[for=mc-check]）三者必须是 body 直接子元素，顺序 check→tree→overlay，保证 ~ 兄弟选择器生效
- #mc-overlay：fixed 全屏 rgba(0,0,0,.85)，flex 居中，opacity:0 + pointer-events:none；#mc-check:checked ~ #mc-overlay{opacity:1;pointer-events:auto}
- 文字用「单个 <text> + 14 个 <tspan>」让浏览器自动按字宽排版（禁止手算 x 摆多个 <text>，会错位重叠）：
  <svg viewBox="0 0 1400 260" preserveAspectRatio="xMidYMid meet" style="width:min(94vw,1400px)">
    <text x="40" y="175" text-anchor="start" font-family="'Brush Script MT','Segoe Script',cursive"
      font-size="130" fill="none" stroke="#fff" stroke-width="2.5"
      style="filter:drop-shadow(0 0 8px rgba(255,60,60,.9))">
      <tspan class="mc-letter" style="animation-delay:0s">M</tspan>……（空格用 <tspan> </tspan>）
    </text>
  </svg>
- 纯描边动画（不要 clip-path 遮罩）：
  .mc-letter{opacity:0;stroke-dasharray:1200;stroke-dashoffset:1200;animation-fill-mode:both}
  #mc-check:checked ~ #mc-overlay .mc-letter{
    animation-name:mcdraw;animation-duration:0.6s;animation-timing-function:linear;animation-fill-mode:forwards}
  @keyframes mcdraw{0%{opacity:0;stroke-dashoffset:1200}1%{opacity:1}100%{opacity:1;stroke-dashoffset:0}}
- 节奏：单字 0.6s，步进 0.25s（第 i 个字母 animation-delay = i*0.25s），流水线书写，整句约 3.85s
- dasharray 必须足够大（1200），否则 130px 字母周长超过会截断

【九、dom 桥接与环境限制（踩过的坑，务必遵守）】
- 扩展页面有 CSP：动态 insertAdjacentHTML 插入的 <script> 不执行，内联 onclick 也不执行 → 事件/动画一律用纯 CSS 或原生 HTML 元素（如 <audio controls>），不要依赖注入脚本或内联事件
- app 执行器里 new AudioContext() 会 Illegal invocation → Web Audio 合成在此环境不可行，音乐用 <audio> 外链
- dom.call 不支持 setAttribute / ownerSVGElement 等；改属性请用 dom.set(sel,"innerHTML"|"outerHTML",...) 整体重建
- SVG <defs> 内元素无法被 ~ 兄弟选择器选中，遮罩方案不可行
- getBBox / querySelectorAll 返回值无法序列化，不要依赖其数值
- 给按钮改文字色时用 -webkit-text-fill-color 兜底，并提高选择器特异性
