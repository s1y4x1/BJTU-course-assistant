# 通义千问代码执行约定

通义千问需要计算或使用扩展能力时，可以在回复末尾放置一个 JavaScript 代码块。代码块必须是回复的最后一项，一次回复只能执行一个代码块。扩展会把执行结果作为下一条上下文发回千问。

## `sandbox`

```sandbox
[1, 2, 3].map((value) => value * 2)
```

- 在扩展的隔离沙箱中执行，不弹出授权询问。
- 适合纯计算、筛选、聚合和数据格式转换。
- 不能访问 `app.html`、页面 DOM、扩展后台或 `chrome.*` API。
- 单个表达式可直接作为结果返回；多条语句需要显式 `return`。

## `app`

```app
ve.login()
```

- 代码由隔离执行器求值，并通过受控桥访问当前 `app.html`；执行前需要用户授权。
- 可以直接调用 app 页面上的全局函数，无需额外的字符串路径调用器。
- 各课程模块的操作会安装到页面上的同名命名空间中，例如 `ve.login()`、`ve.assignments({...})`、`ykt.courseList()`。
- 模块操作仍会经过统一的操作注册表、登录检查和参数处理。
- 单个函数调用可以直接作为代码块末尾的表达式。扩展会自动等待其 Promise，因此无需书写 `await`；多条语句仍可按普通异步 JavaScript 使用 `await` 和 `return`。
- 页面对象同样通过跨上下文桥访问，函数参数及返回值必须可序列化；不能把回调函数或真实 DOM 节点跨上下文传递。

## `background`

```background
chrome.tabs.query({})
```

- 代码由隔离执行器求值，并通过受控桥访问扩展的后台 Service Worker；执行前需要用户授权。
- 可以直接调用后台全局函数或扩展已有权限的 `chrome.*` API，无需额外的字符串路径调用器。
- 常见用途包括查询或管理标签页、读取扩展存储、读取 Cookies、发送系统通知，以及调用后台模块公开的函数。
- 后台没有页面 DOM；不能使用 `document` 或依赖页面元素。
- Service Worker 可能休眠，不应依赖未持久化的长期内存状态。
- 参数和返回值必须能够跨上下文传递。函数、DOM 节点、循环引用和过深对象只会返回受限的可序列化描述。

## 授权与限制

- `sandbox` 自动执行；`app` 和 `background` 会显示“继续 / 始终允许 / 终止”。“始终允许”只对当前对话运行期间的同一种执行环境生效。
- 桥接路径禁止访问 `__proto__`、`prototype` 和 `constructor`。
- 单次代码执行默认最多等待 30 秒；跨页面调用的总等待时间最多约 45 秒。
- 不再提供 `qwen.executeJs` 操作。代码执行由上述末尾代码块直接触发。
