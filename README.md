## 能做什么

| 场景 | 功能 |
| --- | --- |
| 课程与作业 | 聚合智慧课程平台、雨课堂、每日交作业、接龙管家、中国大学 MOOC、学堂在线和 CITEL；区分逾期、未交、已交，按类型筛选 |
| 文件处理 | 上传与附件选择、重复文件检测、资源空间、课程资源和回放下载、在线预览、扩展下载管理 |
| 截止提醒 | 多个提前提醒节点、按平台刷新、智慧课程平台账号选择及登录维护 |
| 校内服务 | SSO/CAS 与 MIS 登录衔接、教务课表/成绩/考试、邮件收件箱及正文预览 |
| AI 与自动化 | AI 助手、扩展接口命令控制台、本地 HTTP/MCP Bridge，按操作授权 |
| 局域网协作 | 聊天室、好友与群聊、文件传输和屏幕共享；需要相应发现服务器与网络条件 |
| 使用方式 | 全屏工作台、弹出窗口、浏览器边栏；模块化安装、字号/颜色/动画设置 |
| Android（实验） | 轻量运行层，独立下载和更新扩展代码；仅支持部分模块 |

不同平台和账号支持的功能不同，具体以扩展界面为准。部分系统需要校园网或 VPN。

### AI 助手

在扩展选项的「AI 助手」中选择模型来源：qwen.ai、浏览器 Prompt API，或 OpenAI-compatible API。

- Ollama：先启动本机 Ollama 并下载模型，选择预设（`http://127.0.0.1:11434/v1`），API Key 可留空，刷新并选择已安装模型。
- Agnes AI：选择预设，填写在 Agnes 平台申请的 API Key，默认选择 `agnes-3.0-flash`（若模型列表包含它）。限流或额度不足时会显示服务返回的具体原因。
- DeepSeek：选择预设，填写 API Key，再从模型列表中选择模型。
- 其他兼容服务：填写包含 `/v1` 的 API 基础地址和密钥。优先通过 `/models` 获取可用模型；获取失败或列表为空时才显示手动输入框。

可设置 Temperature、Top-p、最大输出 Tokens；Ollama 和 Agnes AI 还可设置 Top-k，留空采用服务默认值。「回答前让模型思考」按预设转换为对应服务参数，也可手动选择思考参数格式。是否支持这些参数取决于具体模型；DeepSeek 思考模式不发送 Temperature。Ollama 使用原生 `/api/chat`，以支持 `think`、Top-k 和流式思考输出。

Ollama 返回空正文的 HTTP 403 时，通常是来源限制：将 `OLLAMA_ORIGINS` 配置为允许 `chrome-extension://<本扩展ID>`（在扩展管理页查看 ID），保留原有允许来源，并完全退出、重新启动 Ollama。只重新加载扩展不会改变服务端的来源配置。[官方说明](https://docs.ollama.com/faq#how-can-i-allow-additional-web-origins-to-access-ollama)

兼容接口的会话保存在扩展本机；聊天内容将发送到设置的服务地址。切换服务地址会清除旧密钥并开始新会话，避免串用其他服务的历史。请勿公开导出的设置，其中可能包含密钥。

同时安装 LLM 与聊天室后，可在选项中二选一：「在扩展全屏页面上显示 AI 助手按钮」或「合并入聊天室」，首次检测默认选择后者。选择独立按钮时，聊天室不显示 AI 助手。合并后，未读回复计入助手会话和聊天室图标的角标，查看后清零。助手与其他会话一起排序，可长按或右键手动置顶，不默认置顶；聊天记录和操作授权共用。

接口参考：[Ollama](https://docs.ollama.com/api/openai-compatibility)、[Agnes AI](https://github.com/AgnesAI-Labs/skills/blob/main/agnes-ai-models/references/agent_compatibility.md)。

qwen.ai 的新建会话、生成请求优先在扩展后台完成：读取当前网页版本，并通过官方刷新接口校验/刷新令牌。预检查无法完成时，仅尝试复用已打开的 `chat.qwen.ai` 页面，沿用站点 token 管理器及安全组件，不自动新建或跳转标签页；如果需要登录或验证，请手动在站点完成。生成请求已经发出后，不会因失败而静默重发。`thinking_format` 保持 `detail`；`Bad_Request` 这一通用错误本身不能确定具体原因。

## 详细操作指南

### 1. 准备浏览器和网络

推荐使用近期版本的 Microsoft Edge 或 Google Chrome。浏览器必须支持 Manifest V3 扩展；Firefox 和手机浏览器不能直接使用本项目的 Chromium 扩展包。

部分学校系统需要校园网或学校提供的 VPN。可以先确认平台原网站能够正常访问；扩展不会绕过学校的网络或账号权限。

### 2. 下载并加载扩展

### 方法一：手动下载

1. [下载扩展 ZIP](https://s1y4x1.github.io/BJTU-course-assistant-main.zip)。
2. 将 ZIP **完整解压**至长期保留的位置。不要在压缩包内直接运行，也不要选择临时解压目录。
3. 打开浏览器扩展管理页：`about://extensions`。
4. 开启「开发人员模式」或「开发者模式」。
5. 点击「加载解压缩的扩展」或「加载已解压的扩展程序」。
6. 选择**直接包含 `manifest.json` 的文件夹**，不要选 ZIP，也不要选外面多包了一层的文件夹。
7. 在浏览器扩展菜单中找到「BJTU 课程助手」，建议固定到工具栏。

安装目录不能随意移动或删除，否则已加载的扩展及本地 Bridge 命令可能失效。浏览器提示开发者模式扩展时，请先核对本项目来源，不要为了消除提示关闭浏览器安全功能。

### 方法二：Windows 快捷下载脚本

在合适的位置打开 PowerShell，先审阅[下载脚本](https://s1y4x1.github.io/dl)，确认后执行：

```powershell
irm s1y4x1.github.io/dl | iex
```

这条命令会下载并执行远程脚本，并非浏览器扩展商店安装。下载完成后，仍应按上面的步骤在浏览器加载解压后的目录。

### 3. 第一次打开和登录

1. 点击扩展图标。可在设置中的「窗口与页面」选择弹出窗口、全屏页面或边栏。
2. 推荐先进入全屏课程助手，方便同时查看课程、文件和作业。
3. 智慧课程平台可在顶部填写账号，或从账号面板选择已保存账号；首次登录按提示填写密码或验证码。
4. 在课程助手顶栏启用需要的平台。各平台的登录状态独立；需要网页登录的平台会打开登录窗口。
5. 等待课程与作业加载完成。状态按钮和进度条可用来区分加载中、已登录、未登录等状态。

如果提示初始化账号列表，请仅导入自己有权使用的数据；不需要时按界面提供的跳过或返回操作继续。账号导入导出可能包含密码或登录凭据，不要把它们提交到 GitHub、截图或发到群聊中。

### 4. 查看和处理作业

- 点击平台按钮加载课程；按钮文字行为可以在「平台显示与加载」中调整。
- 作业按逾期、未交、已交等状态分组。点击分组按钮或「查看作业详情」展开内容。
- 在「平台显示与加载」选择要显示的作业类型；不同平台支持的类型不同。
- 智慧课程平台支持在扩展中准备附件和提交作业；其他平台的入口按页面提示操作。
- 不要仅凭扩展的显示判断是否提交成功。重要作业请回到平台原站核对提交记录。

### 5. 文件上传、资源和下载

1. 在「文件上传」选择、拖放或粘贴文件。
2. 上传完成后可以复制链接、下载或将文件选作作业附件。
3. 「资源空间」展示智慧课程平台中的资源；课程卡片还可提供资源、回放及归档等入口，具体取决于账号权限。
4. 「在扩展中下载」控制是否先在扩展内下载并显示进度；部分打包下载仍直接交给浏览器。
5. 「扩展下载」用于管理扩展保存的文件。目录写入或自动保存功能需要按提示授权安装目录。

并行任务过多可能影响浏览器响应，可在设置中降低并行数。留空表示不限数量的选项，以其旁边的说明为准。

### 6. 设置作业截止提醒

1. 打开「扩展选项」→「作业截止提醒」。
2. 配置提前多久提醒，以及要后台刷新的平台。
3. 智慧课程平台可选择提醒账号、后台维护登录状态和是否仅提醒该账号作业。
4. 确认浏览器与操作系统均允许通知，可使用「发送测试通知」检查。

提醒依赖最近成功获取的作业数据和平台接口。浏览器完全退出、系统禁止后台运行、账号失效或校园网不可达时，不能保证准时刷新；不要把它当作唯一的截止时间记录。

### 7. 授权目录和更新

1. 在「扩展选项」→「更新」点击「授权扩展安装目录」（已有权限时显示相应状态）。
2. 选择当前浏览器加载的那一份扩展目录，并允许更改。不要选择同名备份副本。
3. 按浏览器提示和扩展说明完成权限验证；若建议重新加载，确认后再检查授权状态。
4. 检查更新，查看更新说明，确认保留模块后安装。

「清理全部资源，进行全新安装」会移除旧扩展文件再安装，请谨慎使用；`downloads/` 不在该清理范围内。更新中断时保留错误信息，可重新下载并解压修复。需要重新下载时仍可使用上面的下载链接或 PowerShell 命令。

### 8. 可选：AI 助手与本地程序接口

AI 助手与本地程序 Bridge 都依赖「扩展接口」模块。仅使用课程和作业功能不需要安装 Node.js。

- AI 助手：在模块设置中打开助手并登录对应服务；操作调用受扩展接口权限控制。
- 浏览器命令控制台：从「扩展接口」设置进入，可查看操作列表和说明。
- 本地 Bridge：先安装 Node.js 20+，再按[安装与使用说明](modules/local-bridge/README.md)操作。

安装并连接 Bridge 后，可在终端尝试：

```text
BJTUCA
help
api.operationList
help ve.login
```

以当前版本 `help` 和接口说明输出为准。Bearer Token 等同于本地接口凭据，不要公开；仅在明确需要且了解授权影响时开启局域网访问。

### 9. Android 运行层（实验）

Android APK 下载地址由[版本信息](https://s1y4x1.github.io/release.json)的 `apk` 字段提供。桌面全屏页面也会在该字段可用时推荐扫码下载；没有该字段时不会生成无效下载入口。

1. 下载 APK，按 Android 系统提示确认安装。需要时仅对可信来源允许安装应用。
2. 打开应用，选择「下载并安装扩展」。首次使用需要联网下载业务代码。
3. 手机会解压并适配受支持模块，再进入工作台。已安装的代码可离线打开，但平台登录和数据加载仍需联网。
4. 顶栏「更新」可检查扩展更新；启动完成后也会自动检查，应用处于前台时继续定期检查。
5. `release.json.apk` 指向更新版应用时，可下载并交由系统覆盖安装；包名、版本及签名不匹配的安装包会被拒绝。

Android 目前仅支持智慧课程平台、SSO、教务、邮件和验证码模块，不代表桌面所有功能均已移植。应用被系统终止后不能保证持续提醒。真机网络、系统 WebView 与学校接口差异仍可能影响使用。

### 10. 常见问题与反馈

| 问题 | 先检查什么 |
| --- | --- |
| 加载目录时报找不到清单 | 是否完整解压，所选目录是否直接包含 `manifest.json` |
| 平台加载失败或反复要求登录 | 原站能否打开、是否需要校园网/VPN、账号是否仍有效 |
| 没收到通知 | 浏览器和系统通知权限、后台运行状态、最近一次成功加载时间 |
| 无法写入更新目录 | 是否选中当前安装目录、浏览器是否仍授予写入权限 |
| 本地 Bridge 连接失败 | 进程是否运行、端口与连接目标是否一致、是否已有其他扩展连接 |
| Android 提示 APK 签名不同 | 新旧 APK 是否来自同一签名来源；不要先卸载来绕过提示，以免丢失数据 |

在 [Issues](https://github.com/s1y4x1/BJTU-course-assistant/issues) 反馈时，提供扩展/应用版本、浏览器/Android 版本、平台、复现步骤和第一条错误。请先删除学号、密码、Cookie、Token、邮件正文和其他个人信息。

## 可选模块，不必全部安装

- 只查看课程和作业：启用所需课程平台即可。
- 需要教务或邮件：安装对应模块，按界面完成认证。
- 需要 AI 或本地程序调用：安装「扩展接口」，再选择AI 助手或本地 Bridge；普通使用无需 Node.js。
- 需要公式与代码高亮：在外观设置中按需下载 Markdown 渲染组件。
- 需要局域网聊天：安装聊天室模块，并配置可连接的发现服务器。

模块安装和扩展更新涉及目录写入时，请授权当前浏览器加载的安装目录，不要选择备份副本。

## 数据、权限与边界

- 账号导出可能包含密码或登录凭据。不要公开账号文件、Cookie、Token、邮件正文或未打码截图。
- 平台请求需要对应登录状态与网络可达性；扩展不能保证学校接口始终可用。
- 通知依赖浏览器/系统权限、运行状态与最新获取的数据，不替代个人日程安排。
- 本地 Bridge 和 AI 操作有权限控制。不要向陌生程序泄露 Bearer Token；谨慎开放局域网访问。
- Android 版目前是实验功能，支持范围和限制见[Android 说明](#9-android-运行层实验)。
